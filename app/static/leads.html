Your details (go in every email)

Google Maps key

  1. Open Google Cloud ↗, sign in and create a project (any name).
  2. Turn on Places API (New) ↗. Google asks for a card; the first 1,000 searches a month are free and the app stops at your limit above.
  3. Go to Credentials ↗ → Create credentials → API key, and paste it here.

Preview links (GitHub Pages)

  1. Create a new repo ↗ named previews, set to Public, and tick "Add a README".
  2. In the repo: Settings → Pages → Source: Deploy from a branch, branch main, folder / (root) → Save.
  3. Create a fine-grained token ↗: Repository access → Only select repositories → previews; Permissions → Contents → Read and write. Paste it below.
